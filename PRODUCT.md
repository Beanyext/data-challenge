# CQA

## Register

product

## Users

Проверяющий качества поддержки, оператор, оспаривающий оценку, и жюри хакатона. Работа за ноутбуком: прочитать диалог, проверить вывод модели по конкретной реплике, сохранить решение.

## Product Purpose

Интерфейс для шести функций из `reports/условие.md`: редактирование чек-листа, запуск оценки, результат с доказательствами, карточка разговора и аудио, апелляция и пересмотр. Сервер и модель разрабатываются отдельно; контракт в `reports/задачи.md`.

## Brand Personality

Понятный, точный, спокойный. Пользователь выбрал визуальный ориентир Freedom Bank. Это прототип команды, а не официальный банковский сервис.

## Anti-references

Маркетинговый лендинг вместо рабочего экрана; декоративные графики без данных; неподписанные демонстрационные оценки; сокрытие доказательств за несколькими переходами.

## Design Principles

- Доказательство и диалог видны рядом.
- Исходная оценка и решение проверяющего различимы.
- Учебные данные явно отделены от API и никогда не заменяют его молча.
- Изменение критериев возможно без изменения кода.
- Отсутствие результата отличается от нулевой оценки.

## Accessibility & Inclusion

Русский интерфейс с транскриптами RU/KZ/EN. Семантические формы, видимый фокус, клавиатурная навигация, текстовые статусы помимо цвета, уменьшение движения по настройке системы. Контраст текста целевой не ниже 4.5:1. Адаптация к узкому экрану.
