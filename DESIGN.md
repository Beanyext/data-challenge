# CQA interface

Проверяющий работает в освещённом офисе, долго читает сообщения и сверяет их с оценкой: светлая тема, спокойные нейтральные поверхности и зелёный акцент в духе Freedom Bank.

## Visual theme

Сдержанный рабочий интерфейс. Чёрная типографика, светло-серый фон, белые рабочие области, зелёный цвет выбранных действий. Никаких внешних шрифтов, трекеров и загружаемых библиотек.

Аудитория включает руководителей, директоров и сотрудников компании. Без персонажей, игровых элементов и рекламных слоганов. Тёмно-зелёная боковая панель отделяет навигацию от светлой рабочей области. Линейные SVG-иконки React находятся в `web/react/shared.tsx`, логотипы — в `web/assets/`. Критические отметки подписаны словами; рядом со сводкой обозначен охват показателей.

## Color

Основной зелёный задан по выбранному пользователем брендовому направлению Freedom. Базовые стили находятся в `web/styles.css`; визуальные слои подключаются в `web/index.html`, последние интеграционные поправки — в `web/merged.css`. Яркая заливка используется с тёмным текстом; ссылки имеют отдельный тёмно-зелёный цвет. Ошибка красная, ожидание янтарное; у каждого состояния есть текст. На проверенных обычных текстах контраст от 4.79:1; это выборочная проверка, не полный аудит доступности.

## Typography

Системный sans-serif, 14px основного интерфейса, 15px транскрипта. Фиксированная rem-шкала. Табличные цифры для баллов и времени. Крупный балл только в карточке результата.

## Components and layout

Один React-root управляет всеми страницами и формами. Боковое меню, компактная верхняя панель, таблица диалогов с выбором плотности, двухколоночная карточка, встроенный редактор критериев, очередь апелляций и выгрузка. В карточке закреплена сводка, карта критериев ведёт к обоснованиям, доказательство выделяет исходную реплику. Режим «Фокус» освобождает место для чтения.

На узком экране меню становится верхней навигацией, карточка складывается в одну колонку. Основные мобильные действия имеют размер не менее 44px. Короткие формы открываются в нативном модальном диалоге с блокировкой повторной отправки. Ошибки API показываются явно; учебные данные включаются отдельным действием.

RU/EN/ҚАЗ переключаются без перезагрузки. Введённые пользователем тексты и исходные диалоги не переводятся. Для печати используется отдельная React-разметка полного транскрипта: A4, локальный логотип, Arial, без навигации и кнопок.
