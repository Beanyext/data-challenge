# Проверка интерфейса CQA

Проверено 7 ноября 2026 года, локально в ветке `bekmurat/work`. Основное окружение: обычный статический HTTP-сервер на loopback и Chromium через Playwright MCP. Живой сервер CQA отсутствует, что подтверждено пользователем. Чужие ключи, реальные транскрипты и платные модели не использовались.

## Автоматические проверки

`node --test web/tests/*.test.mjs`: 90 тестов прошли. Проверяются API-адаптер, учебные данные и сохранение решений, сравнение чек-листов, очереди и фильтры, соответствие исходной версии, контекст реплик и безопасный отчёт. Дополнительно проверяются схема сдачи 1.0, источники оценок и CLI-проверка итоговых файлов. Нулевой итог, отсутствие итога, пустая выборка, изменённые шкалы, N/A, HTML-символы и неправильные ссылки покрыты отдельными случаями.

`node --check web/app.mjs` и `git diff --check`: без ошибок.

## Браузер

- `browser-smoke.js`: основные шесть функций, поиск и пустая выдача, сохранение при перезагрузке, загрузка некорректного JSON, экранирование HTML, клавиатурный переход к содержимому, размеры 320/390/768/1440. Без ошибок JavaScript страницы.
- `browser-api.js`: запросы перехвачены тестовым сервером, сохраняющим и возвращающим отправленные данные. Проверены запись/чтение чек-листа и решения, один POST оценки при повторном submit, восстановление опроса задания, остановка на ошибке, HTTP 503 и некорректный формат списка. Дополнительно: нельзя закрыть медленное сохранение и затереть новую правку; неверная версия чек-листа не подставляется и блокирует пересмотр. Платных вызовов нет.
- `browser-security.js`: повреждённый диапазон не создаёт HTML; правильный диапазон продолжает работать. Повреждённый подписанный аудиоадрес не выводится в ошибке.
- `browser-improvements.js`: объединённая очередь и фильтры, переключение охвата сводки, пустая выборка, контекст и черновик апелляции, сохранение/отмена предпросмотра, отсутствие новой версии без изменений, применение добавленного критерия, отчёт с исходной и финальной оценкой, переход к аудиофрагменту без автозапуска. На ширинах 320/390/768/1440 страница не выходит за viewport.
- `browser-submission.js`: 17 сценариев прошли. Проверено фактическое содержимое скачанных файлов для полного PROD10 и DEV65, типы восьми критериев, team_name `seeusoon`, исходные ID и номера реплик с 1. Прогнаны пустой ввод, повреждённый JSON, дубли, пропуски, посторонние ID, demo/mock, повтор после правки команды, автоматическое обновление модели при замене файлов, оригинальная/финальная оценка и подтверждение предупреждений. Ошибка чтения одного результата сохраняется среди всех 10 записей; перед скачиванием требуется подтверждение. Возможные контакты в обосновании дают предупреждение без вывода самих контактов. Серверный сбор — 11 перехваченных GET, без POST и внешних запросов. Ошибок JavaScript нет; размеры 320/390/768/1440 без горизонтального переполнения.

Новые проверки используют исключительно вымышленные фикстуры, не настоящие ответы для сдачи. CLI проверен через дочерний Node-процесс на чтении UTF-8/BOM, корректных DEV/PROD, ошибках ID/схемы/аргументов и неизменности исходных файлов. Контрольные мутации в отдельных временных копиях обнаружены тестами: неверный вес `dialogue`, игнорирование чужого conversation_id и успешный код CLI при невалидном JSON. Ошибка повторной кнопки после изменения текста воспроизведена в браузере до исправления и перепроверена после.

## Печать

PDF учебного отчёта сформирован Chromium на A4. Проверены все шесть страниц: баллы, критерии, контекст и решение присутствуют; пустых страниц нет; панель навигации и кнопки не печатаются; заголовки критериев не разрываются. Используется Arial, чтобы извлекаемый текст PDF сохранял правильную кириллицу. Это проверка механизма экспорта на вымышленных данных, а не отчёт о точности AI.

## Что остаётся проверить с командой

Реальный сервер должен реализовать маршруты из `README.md`, возвращать точные снимки версий, баллы и признаки для очереди. После его появления нужен сквозной прогон на реальных DEV-диалогах, включая звонки и пересмотр. Точность относительно Ground Truth этими тестами не измеряется. Открытие репозитория, сдача, деплой и новые платные вызовы не выполнялись.
