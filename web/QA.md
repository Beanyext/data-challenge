# Проверка интерфейса CQA

Проверено 7 ноября 2026 года в ветке `bekmurat/work`. Объединены функции нашей версии `56bee02` и обновления React-ветки `c3f18fa`. Основное окружение: Node.js, статический HTTP-сервер на loopback и Chromium через Playwright MCP. Настоящий FastAPI/SQLite команды также проверен в изолированной копии с mock-провайдером. Чужие ключи, реальные транскрипты и платные модели не использовались.

## Автоматические проверки

`npm run typecheck` и `npm test` прошли: **145 тестов, 145 успешных, без пропусков**. Команда тестирования сначала собирает `web/react-ui.js`; интеграционный тест запускает именно этот bundle в JSDOM. Исходники проверяются строгим TypeScript. Проверяются API-адаптер, учебные данные и сохранение решений, React-страницы и формы, локализация, сравнение чек-листов, очереди и фильтры, соответствие исходной версии, контекст реплик и отчёт. Дополнительно проверяются схема сдачи 1.0, источники оценок и CLI. Нулевой итог, отсутствие итога, пустая выборка, изменённые шкалы, N/A, HTML-символы и неправильные ссылки покрыты отдельными случаями.

Отдельные регрессии: неизменённые `original_answer` и `original_total: null` не означают пересмотр; пропущенный ответ отличается от N/A; неполная оценка помечается как предварительная; mock не выдаётся за настоящую модель. Отчёт скрывает известные форматы данных доступа, включая JSON с кавычками и вложенные поля. Это не полное обезличивание произвольного текста. Новые тесты воспроизводили ошибки до исправления.

`node --check web/app.mjs` и `git diff --check`: без ошибок.

## Браузер

- `browser-smoke.js`: основные шесть функций, поиск и пустая выдача, сохранение при перезагрузке, загрузка некорректного JSON, экранирование HTML, клавиатурный переход к содержимому, размеры 320/390/768/1440. Без ошибок JavaScript страницы.
- `browser-api.js`: запросы перехвачены тестовым сервером, сохраняющим и возвращающим отправленные данные. Проверены запись/чтение чек-листа и решения, один POST оценки при повторном submit, восстановление опроса задания, остановка на ошибке, HTTP 503 и некорректный формат списка. Дополнительно: нельзя закрыть медленное сохранение и затереть новую правку; неверная версия чек-листа не подставляется и блокирует пересмотр. Платных вызовов нет.
- `browser-security.js`: повреждённый диапазон не создаёт HTML; правильный диапазон продолжает работать. Повреждённый подписанный аудиоадрес не выводится в ошибке.
- `browser-improvements.js`: объединённая очередь и фильтры, переключение охвата сводки, пустая выборка, контекст и черновик апелляции, сохранение/отмена предпросмотра, отсутствие новой версии без изменений, применение добавленного критерия, отчёт с исходной и финальной оценкой, переход к аудиофрагменту без автозапуска. На ширинах 320/390/768/1440 страница не выходит за viewport.
- `browser-submission.js`: 17 сценариев прошли. Проверено фактическое содержимое скачанных файлов для полного PROD10 и DEV65, типы восьми критериев, team_name `seeusoon`, исходные ID и номера реплик с 1. Прогнаны пустой ввод, повреждённый JSON, дубли, пропуски, посторонние ID, demo/mock, повтор после правки команды, автоматическое обновление модели при замене файлов, оригинальная/финальная оценка и подтверждение предупреждений. Ошибка чтения одного результата сохраняется среди всех 10 записей; перед скачиванием требуется подтверждение. Возможные контакты в обосновании дают предупреждение без вывода самих контактов. Серверный сбор — 11 перехваченных GET, без POST и внешних запросов. Ошибок JavaScript нет; размеры 320/390/768/1440 без горизонтального переполнения.
- `browser-react-workflows.js`: живые RU/EN/ҚАЗ без reload, сохранение фильтров, выделения, текстов, необработанной шкалы, черновика решения и файлов выгрузки. Режим «Фокус», связанные доказательства и возврат к карте. Шесть страниц на ширинах 320/390/768/1440: 24 сочетания без горизонтального переполнения. В печати весь транскрипт, без дублирования экранного блока и навигации.
- `browser-connection.js`: неверный сохранённый API блокируется без GET и подмены источника; подготовка из файлов остаётся доступной. Отмена перехода в demo сохраняет несохранённый чек-лист, подтверждение явно переключает источник.
- `browser-live-api.js`: настоящий FastAPI и SQLite команды, описанные ниже. Перед POST проверяется, что `/api/health` сообщает провайдер и модель `mock`.

Новые проверки используют исключительно вымышленные фикстуры, не настоящие ответы для сдачи. CLI проверен через дочерний Node-процесс на чтении UTF-8/BOM, корректных DEV/PROD, ошибках ID/схемы/аргументов и неизменности исходных файлов. Контрольные мутации в отдельных временных копиях обнаружены тестами: неверный вес `dialogue`, игнорирование чужого conversation_id и успешный код CLI при невалидном JSON. Ошибка повторной кнопки после изменения текста воспроизведена в браузере до исправления и перепроверена после.

## Печать

PDF учебного отчёта сформирован Chromium на A4. Проверены все шесть страниц: баллы, критерии, контекст и решение присутствуют; пустых страниц нет; панель навигации и кнопки не печатаются; заголовки критериев не разрываются. Используется Arial, чтобы извлекаемый текст PDF сохранял правильную кириллицу. Это проверка механизма экспорта на вымышленных данных, а не отчёт о точности AI.

## Проверка настоящего API

Сначала проверен снимок backend `b6ca357`, затем изменения `8a0e957` после аудита: явные MIME-типы статики и `original_total: null` до решения апелляции. Сервер запущен в отдельной временной папке и Python-окружении, с пустой SQLite и только вымышленными диалогами. Провайдер принудительно `mock`, `.env` не загружается, внешние соединения запрещены. Импорт организаторов и серверная загрузка аудио исключены из этого прогона. Код backend в рабочую ветку интерфейса не переносился.

Проверены multipart-загрузка и чтение, фоновая mock-оценка с одним POST, апелляция с исходным контекстом, решение и пересчёт, чтение после reload, отчёт с исходным/финальным баллом и пометкой mock, новая версия чек-листа без изменения исторической оценки. Mock-оценки блокируются при официальной выгрузке.

После ручного решения текущий API не передаёт полный `original_criteria`. Для выгрузки исходной оценки нужен такой снимок из оценщика/API; восстановление исходных доказательств из финальных запрещено. Можно явно выбрать финальные ответы.

## Границы проверки

Реальные DEV/PROD, точность относительно Ground Truth, платная модель и интеграция Dynamics 365 не проверялись. Аудиопереход проверен в учебном режиме и на HTTP-стенде; реальное хранение записей и получение сервером подписанной ссылки требуют отдельного прогона команды. Публикация, сдача и деплой не выполнялись.
