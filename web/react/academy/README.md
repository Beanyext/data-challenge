# Freedom Academy

Локальный демонстрационный тренажёр информационной и технической поддержки **Freedom Broker**. Это независимый раздел существующего React-интерфейса, а не система оценки сотрудников или инвестиционных рекомендаций.

## Открытие

В боковом меню сайта — **Freedom Academy → Тренировка оператора**.

- `/#academy` — карта и прогресс.
- `/#academy/missions` — прямой переход к карте; `/#academy/history` — история и навыки.
- `/#academy/mission/login/story` — первая миссия.
- `/#academy/result/<attemptId>` — сохранённый результат.
- `?lang=ru`, `?lang=kk`, `?lang=en` — существующий переключатель языка с обновлением страницы.

Применена существующая hash-маршрутизация, поэтому прямые ссылки не требуют новых серверных маршрутов. Навигация из незавершённой миссии требует подтверждения и сохраняет подготовленные ходы для продолжения.

## Состав

- `types.ts` — контракты графа, учебных проверок, сессий и прогресса.
- `missions.ts` — восемь вымышленных брокерских ситуаций, учебные факты, варианты ответов, ветки исправления и переводы RU/KK/EN.
- `engine.ts` — переходы, эмоции, учебная оценка, XP, достижения, календарные режимы и проверка сохраняемых данных. `LocalResponseSource` — локальная реализация интерфейса источника ответов.
- `AcademyApp.tsx` — интерфейс и взаимодействия.
- `AcademyConfirm.tsx` — подтверждения выхода, замены сессии и сброса через нативный модальный `dialog`.
- `persistence.ts` — объединение завершённых попыток между вкладками; оценивание остаётся в прежнем движке.
- `copy.ts` — тексты интерфейса на трёх языках; текущий язык берётся из общей системы локализации.
- `../../academy.css` — стили только Academy и её кнопки входа, адаптивная раскладка и поддержка reduced motion.

Интеграция ограничена `web/index.html` (кнопка и CSS), `web/app.mjs` (маршруты до сетевых запросов основного сайта), `web/react/index.tsx` (React-монтирование и проверка выхода), `web/react/messages/common.ts` (перевод навигации) и пересобранным `web/react-ui.js`. Backend, реальный оценщик и его чек-листы не изменены.

Миссии: доступ к торговой платформе, неисполненная заявка, снижение стоимости инвестиций, вывод средств, комиссия, дивиденды, подозрительный доступ, сложная жалоба инвестора. Сведения и действия внутри сценариев — учебные. Никаких котировок, торговых операций, обращений к счетам, моделей или API оценщика модуль не вызывает.

## Оценка и прогресс

Пять критериев: эмпатия 20%, точность 25%, безопасность финансовых коммуникаций 25%, решение обращения 20%, профессионализм 10%. Проверки основаны на уникальных событиях графа. Ошибки сохраняются в истории после исправления; результат показывает соответствующий ход и пример ответа.

Успех требует не менее 70 баллов, выполнения обязательных целей и отсутствия критических ошибок. При критической ошибке безопасность равна нулю, итог не выше 49, XP не начисляется. Спокойствие клиента само по себе не означает успех.

За успешную попытку потенциальный вклад — `round(maxXP × score / 100)`. Начисляется только положительная разница с лучшим вкладом этой миссии. Повторное открытие результата не начисляет XP. Уровень: `min(20, 1 + floor(totalXP / 100))`.

Достижения открываются один раз:

- Первый разговор — завершённая попытка.
- Мастер эмпатии — успешная попытка с начальной напряжённостью ≥46 и снижением минимум на 25.
- Защитник инвестора — успешная миссия `security` без критического нарушения.
- Без ошибок — 100 баллов без подсказок.
- Профессионал — пять разных успешно пройденных миссий.
- Работа над ошибками — улучшение прежнего лучшего результата минимум на 15 баллов.

Испытание дня выбирается по календарной дате в Asia/Qyzylorda. Демонстрационный переключатель открывает все миссии, но не выдаёт награды. Песочница эмоций отделена от прогресса.

## Хранение и ограничения

Пространство хранения: `freedom-academy:broker:progress:v1`, набор сценариев `broker-v1`. Старые результаты банковского набора не переносятся. История ограничена 50 попытками; лучшие вклады и достижения хранятся отдельно. Сохраняются идентификаторы сценарных действий, а не свободный текст. Поэтому уже сыгранный диалог переводится при смене языка.

Повреждённое или недоступное хранилище обрабатывается с уведомлением. При проблемах сохранения работа продолжается в памяти текущей страницы. Смена языка отменяется, если эту сессию не удалось сохранить; обычное закрытие/обновление вызывает предупреждение браузера. При восстановлении доступа запись повторяется. Кнопка сброса затрагивает только данные этого тренажёра; неудачное удаление сохраняет текущее состояние и сообщает об ошибке.

Результат последнего ответа записывается до визуальной задержки. События `localStorage` и повторное чтение перед записью защищают уже полученные результаты другой вкладки. При объединении независимых попыток учитывается максимальный вклад миссии; локальная квитанция XP содержит только ещё не учтённую разницу. Оценки, ответы и идентификаторы попыток сохраняются. Один профиль хранит одну активную сессию; это локальное согласование данных, а не атомарная серверная синхронизация одновременных тренировок.

Свободный ответ — экспериментальное сопоставление с ограниченным набором сценарных действий. Неизвестная или неоднозначная фраза не меняет оценку и эмоции: предлагаются готовые варианты. Это не понимание произвольного текста и не AI-анализ. Реальные данные и секреты вводить не требуется.

## Проверка и показ

Команды из корня репозитория:

```text
npm ci --ignore-scripts
npm run typecheck
npm run build
npm test
```

`academy-engine.test.tsx` проверяет графы, эмоции, оценки, критические ответы, прогресс, хранение и классификатор. `academy-app.test.tsx` проходит все восемь миссий через собранный React-интерфейс, проверяет исправление ошибки и запрещает сетевые вызовы. `academy-copy.test.tsx` проверяет ключи интерфейса, параметры строк и полноту трёх переводов. Для отдельного прогона интерфейса на другом языке можно задать `CQA_ACADEMY_LOCALE=en` или `kk` и запустить собранный `outputs/frontend-tests/academy-app.test.mjs` через `node --test`.

На первом этапе также прошли 145 серверных тестов. На этапе UX-аудита backend не менялся, серверные тесты повторно не запускались. Актуальные проверки интерфейса приведены ниже.

Графитовая палитра и зелёный акцент оформлены локальными токенами Academy. Основной текст, ответы и объяснения — 16 px; элементы управления — минимум 44 px. Состояния отправленного ответа, эмоции и реальные изменения показателей согласованы с данными. При неудаче и при 0 XP нет поздравительной анимации; повтор объясняет, почему награда уже учтена. Поддерживается `prefers-reduced-motion`.
