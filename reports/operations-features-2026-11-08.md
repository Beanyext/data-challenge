Проверено 08.11.2026 до стоп-кода, часовой пояс Asia/Almaty. Ветка `bekmurat/work`, исходный HEAD `6abfe3f`. Коммит, push и PR в рамках этой задачи не выполнялись. Существующий React-интерфейс сохранён.

## Что изменено и зачем

- В списке диалогов добавлены фильтр ошибок и подтверждаемый повтор ошибок текущей выборки. Скрытые фильтрами, успешные и ожидающие записи не переоцениваются. Клиент перечитывает статусы, сервер проверяет их вместе с созданием задания под блокировкой SQLite-store; устаревшая выборка получает HTTP 409 без нового задания. Это уменьшает лишние перезапуски и сохраняет успешные результаты.
- В меню добавлена аналитика последних сохранённых оценок: потери по критериям, полный средний балл, грубые ошибки и переходы к проблемным диалогам. Группы разделены по ID и версии чек-листа, есть фильтр языка. N/A, пропущенные и непроверенные ответы не превращаются в нули. Некорректные или неполные наборы ответов исключены из среднего полного балла даже при числовом total. Ошибки чтения и несовместимые снимки показаны явно. Аналитика делает только GET-запросы и не измеряет точность модели.
- Под карточкой диалога добавлена история запусков: модель, время Алматы, версия чек-листа, балл, отметки последнего и выбранного запуска. Старый результат открывается со своим снимком правил; прямая ссылка, перезагрузка и отчёт сохраняют этот выбор. Результат чужого диалога отклоняется. История показывает сохранённые запуски, а не отдельные редакции решений апелляций.
- Все новые пользовательские надписи добавлены на RU, EN, KK. Длинные названия и таблица аналитики не растягивают мобильную страницу: таблица прокручивается внутри блока.

Аналитика читает последние оценки с параллелизмом не выше четырёх; пропущенные записи не подменяются старой успешной оценкой. Защита повтора использует блокировку единственного процесса Store, как и текущий сервер; многопроцессный запуск отдельно не проверен.

## Воспроизведение нового браузерного сценария

Из корня проекта запустить `PYTHONUTF8=1 python -m uvicorn operations_server:app --app-dir tests --host 127.0.0.1 --port 8767`. Стенд создаёт новую временную базу при каждом запуске. Затем выполнить функцию из `web/tests/browser-operations.js` в Playwright с объектом `page`, как существующие браузерные наборы проекта. Перед повтором сценария перезапустить стенд: проверка повтора изменяет только его временную базу.
