## Исправления совместимости

- API оценки возвращает полный `original_criteria`, включая исходные доказательства и веса. После решения по апелляции можно выгрузить исходный результат, не подменяя его пересмотренным.
- Завершённое пакетное задание с `failed > 0` или непустым `errors` оставляет предупреждение. Успешное уведомление показывается только без ошибок.
- Перенесены компактные критерии, причины потери баллов, ссылки на номера реплик, время звонка и оценка стоимости запуска из main. Текущая архитектура React и строгие проверки неполных/учебных результатов сохранены.
- Тесты и браузерные сценарии согласованы с раскрываемыми карточками критериев и живым переключением локали.
